# Nursing New Zealand Flashcards

A lightweight study app for iPad, mobile, and desktop.

## Controls
- Tap / Space / Enter: flip card
- Left / Right arrows: previous / next
- 1: Don't know
- 2: Know
- Review mistakes mode
- Shuffle
- Progress saved locally in the browser

## Deployment
Import this GitHub repository into Vercel. No build command is required for this static site.
